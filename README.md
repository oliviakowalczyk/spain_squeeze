# Test-retest reliability of sensorimotor activity measured with spinal cord fMRI

This repository contains code accompanying publication: [https://doi.org/10.1101/2025.09.07.674708](https://doi.org/10.1101/2025.09.07.674708).

## Contents

Full detail of the pipeline are availble in the above manuscript. Briefly, the code is a series of bash scripts using tools from FSL, SCT, and AFNI to preprocess and model spinal fMRI motor task data.

## Data availability

The participants in this study did not give their permission for data sharing, therefore raw data is not available. 
Group-level statistical maps resulting from this analysis, can be found on [Neurovault](https://identifiers.org/neurovault.collection:23114).
